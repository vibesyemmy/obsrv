The updater checks GitHub daily and offers the release page; it never installs. Someone on 0.57.0 has no way to know.

## DONE 2026-10-27, `#637` — merged into `main` at `0.64.3`

**Followed the update-check design's own named precondition** (`docs/superpowers/specs/2026-08-26-update-check-design.md` §10): once signing landed (`a1`, the two CI secrets set the same day), `electron-updater` replaces the "opens a page" toolbar action with "downloads and installs."

**Additive, not a rewrite.** `checkForUpdate` still owns `available`/`current`/`error`, the daily throttle and "Check now" — untouched. A new `src/main/autoUpdate.ts` wraps `electron-updater`: once a check says `available`, it starts a background download against `electron-updater`'s own `latest-mac.yml` feed, adding `downloading` (with `progress`) and `downloaded` states. `downloaded` is the only state with anything to click — a toolbar button and a Settings "Restart to update" link, both calling a new `quitAndInstall` IPC method.

**Build config:** `electron-builder.yml` gained a mac `zip` target (Squirrel.Mac updates from a zip, never a DMG) and an explicit `github` publish config, so electron-builder bakes `app-update.yml` into the bundle and writes `latest-mac.yml` at build time. `ci.yml` attaches the zip, its blockmap, and `latest-mac.yml` to the release.

**Verified, not just shipped:** `v0.64.3` is the first release carrying `latest-mac.yml` + the `.zip`/`.blockmap` pairs for both archs — confirmed on the real GitHub release (`gh release view v0.64.3`), not just the build log.

**Testing gap, carried forward rather than hidden:** `electron-updater`'s real download/install path has no e2e coverage — faking a valid signed-zip-plus-matching-sha512 feed is out of reach for this suite's network-free design. What *is* covered: `downloading`/`downloaded` pushed down the real `IPC.updateStatus` channel, exercising the real toolbar/Settings rendering and `quitAndInstall`'s own main-side gate (`tests/e2e/update.spec.ts`). 141 unit test files green, full e2e 497 passed (1 unrelated flake, retried green).

The next release past `0.64.3` is this feature's first live test: does an app on `0.64.3` actually offer, download and install it.
