# 0.56.0 against the shapes twelve runs had not covered

The thirteenth run, on a stack that is 0.56.0 end to end. Chosen by
archetype rather than by name, to reach what the first twelve missed:
chromestatus.com (a web-components app), aljazeera.net (right-to-left),
play.grafana.org (a dense dashboard), excalidraw.com (a canvas app), and —
the gap that matters most — a **dev server on localhost**, since every run
before this one pointed Obsrv at finished public websites while its users
point it at their own work in progress.

## Held

- **Right-to-left is measured like anything else.** aljazeera.net: 108
  targets, 46 under 7 mm, 281 text elements, 20 screenfuls of a 22,387 px
  page, no warnings. Arabic labels at 3.87 mm reported correctly.
- **A dense dashboard gives dense findings.** play.grafana.org: 32
  targets, 15 under 7 mm — twelve 16 px icon buttons at 4.43 mm, the
  "Close menu" at 4.98 mm. Exactly the chrome a dashboard accumulates.
- **A canvas app is judged on what it draws in the DOM.** excalidraw.com:
  16 contrast findings, all `#b8b8b8` on white at 1.98:1, including the
  welcome screen's own heading. And the 0.53.0 nothing-to-scroll note
  fired on a real product for the first time — a canvas app that hides its
  overflow, named rather than read as a one-screen page.
- **An ordinary dev-server page measures normally**, which is worth
  stating because nothing before this run had tried one.

## Broke or misled, ranked

1. **A page built from web components measures as zero, and every reason
   offered is the wrong one.** chromestatus.com/features answers 0 targets
   and 0 text, with: "nothing to measure: the page had no visible text and
   no targets 3 s after it loaded — a page rendered by script that had not
   run yet, a bot wall, or an empty document … an `<iframe>` covers 0% of
   the viewport".

   None of those is true. Measured in the page: **159 shadow hosts, 136
   interactive elements and 147 text-bearing elements**, all inside shadow
   roots, under a `chromedash-app` root. The snap shows a full page — a
   sidebar, a search field, 25 feature rows, a footer. Obsrv's own figures
   already contradict its sentence: it walked **3 screenfuls of a 3,682 px
   page**, which an empty document cannot do.

   Two defects, of different sizes. The small one: the sentence never
   names shadow DOM, though the walk's own note does — so the reader is
   handed three causes and the true one is absent. The large one: open
   shadow roots are reachable from script, and the measurement does not
   enter them, so every product built on Lit, Polymer, Stencil, FAST or
   Ionic — and the enterprise design systems built on those — is
   unmeasurable, and told it is empty.

2. **A page that navigates while the measurement waits is measured, but
   named as the page you asked for.** A dev fixture that reloads itself
   twice, 1.2 s apart, as an edit-save-edit-save does under HMR: with
   `waitMs: 3000` the audit answers 11 targets — which is revision 2 by
   construction — while reporting `url: …/hmr`, not the `…/hmr?n=2` it
   measured, and carrying no note at all. The navigated-after-load note
   exists and fired on etsy.com in run 9; it does not cover a navigation
   that lands during the settle wait. In dev this is HMR, an auth
   redirect, or a router replacing the URL.

3. **A 4xx page is measured as though it were the page.** The dev
   fixture's missing route answers 0 targets, 2 text elements and no
   warning — the 404 page measured as the subject. A mistyped route, a
   stale dev server or the wrong port all land here, and nothing says so.
   Electron's `did-navigate` carries `httpResponseCode`, so the status is
   available to say it with; whether that is worth wiring is a separate
   question from whether the silence is right.

## What this run says about readiness

The first twelve runs drove finished public websites. This one spent half
its time on a dev server and found two of its three findings there — which
is the argument for making dev-time targets a standing part of every run
rather than an afterthought: localhost, a route that 404s, a page
reloading under the measurement, and eventually a page behind a login.
